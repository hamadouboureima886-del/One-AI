ONE
Une seule barre pour tes calculs, tes notes et ta recherche.
ONE détecte ce que tu tapes et choisit le bon outil :
	•	Calcul : 18% de 2450, (120 + 45) x 3
	•	Note : note: appeler Sam jeudi
	•	Recherche : tape un mot pour retrouver tes notes
Appuie sur Entrée pour enregistrer un résultat ou une note. Un calcul peut ainsi devenir une note, que la recherche retrouve ensuite.
Utilisation
Ouvre index.html dans ton navigateur, ou visite la version en ligne : https://ton-pseudo.github.io/nom-du-depot
Aucune installation ni serveur n'est nécessaire. Le site tient dans un seul fichier.
Tes données
Les notes sont enregistrées dans le navigateur (localStorage). Elles restent sur ton appareil et ne sont envoyées nulle part.
Publier avec GitHub Pages
	1.	Envoie index.html dans le dépôt.
	2.	Va dans Settings, puis Pages.
	3.	Choisis « Deploy from a branch », branche main, dossier / (root).
